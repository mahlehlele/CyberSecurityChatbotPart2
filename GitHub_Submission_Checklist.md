# GitHub Submission Checklist

Use this checklist before submitting on ARC.

## Repository

- [ ] Repository is public or the lecturer has access.
- [ ] Repository link opens in an incognito/private browser.
- [ ] The full WPF project folder is uploaded.
- [ ] `README.md` is visible on the repository home page.
- [ ] `Assets/welcome.wav` is included.
- [ ] `Assets/ascii-logo.png` is included.
- [ ] There are at least six meaningful commits.
- [ ] There are at least three version tags.
- [ ] GitHub releases are created from the tags.

## Suggested real commit messages

1. `Create WPF project structure`
2. `Add chatbot GUI layout and assets`
3. `Translate Part 1 responses into ChatBot service`
4. `Add keyword recognition and random topic responses`
5. `Add memory recall and follow-up handling`
6. `Add sentiment detection and final README`

## Suggested releases

- `v1.0.0` - GUI and Part 1 features complete
- `v1.1.0` - Dynamic responses, keyword recognition, and memory complete
- `v1.2.0` - Sentiment detection, polish, and final submission version

## ARC submission

- [ ] Submit the GitHub link only if ARC requests only the link.
- [ ] Submit the YouTube unlisted video link in the correct place.
- [ ] Test both links before the deadline.
